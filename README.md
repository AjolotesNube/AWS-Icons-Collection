# AWS Icons Collection

Este repositorio contiene los íconos de todos (o casi todos) los servicios de Amazon Web Services (AWS) en formato SVG. Estos íconos están disponibles para su uso libre en proyectos relacionados con la nube de AWS, documentación técnica, y más.

## Contenido

Cada archivo SVG representa el ícono oficial de un servicio de AWS. Puedes buscar y descargar el ícono de cualquier servicio de AWS que necesites. 

Los archivos están organizados en subdirectorios que corresponden a diferentes categorías de servicios, como:

- **Computación**
- **Almacenamiento**
- **Redes**
- **Bases de datos**
- **Seguridad y cumplimiento**
- Y muchos más...

## Uso

Puedes utilizar estos íconos en tus proyectos de cualquier manera que desees, siempre que se respete la licencia de uso de los íconos de AWS.

### Ejemplo de uso

Si deseas agregar un ícono de un servicio en tu página web, solo necesitas el archivo SVG correspondiente. Aquí tienes un ejemplo simple de cómo incluir un ícono SVG en tu HTML:

```html
<img src="path/to/aws-icon.svg" alt="AWS Service Icon" width="100" height="100">
```
